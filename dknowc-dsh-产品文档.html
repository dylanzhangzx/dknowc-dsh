1

产品概览

是什么面向 DeepSeek Harness（dsh）的插件包（bundle），把深知可信搜索、深知可信PPT、深知公文写作三个 Skill 一次性接入 dsh：安装后 skill 出现在会话可用目录，模型按任务自动路由；同时捆绑「深知可信工作台」MCP（trusted_search / deep_query / doc_outline）作为脚本异常时的应急兜底通道。
架构取向① 检索走脚本直连（全量结构化返回：文号、存档快照、标题链、可信度），MCP 返回为精简视图、仅作兜底；② 零 dsh SDK 依赖（入口只用 Node 内置模块 + cordis 注入的 ctx），MCP client 由宿主自带，跨 dsh 大版本天然兼容；③ 产物不落插件目录，按会话隔离写入工作区。
与母版的关系三个 skill 的内容源头是各自 SkillHub 母版；本包按「母版同步 → 重打 dsh 补丁」流程维护（会话隔离路径、dsh Key 三级门禁、渠道码、交付表述、剔除母版专属脚本）。
不做什么不内置 API Key（注册引导获取）；不走 OAuth 取 Key（dsh 捆绑 MCP 为 Bearer 认证）；不修改 dsh 宿主行为；不做宿主交付复制（产物天然在工作区）。

能力矩阵（三 skill）

Skill能力交付物
深知可信搜索
dknowc-trusted-search		 咨询式政策问答（dsh 版由本 skill 承接，不设独立咨询 skill）＋ 权威材料检索 / 深度研究（按问题复杂度分级）；研究资料层（核心事实总表＋数据口径表，缺口驱动补搜）；政策可视化图表并入报告。 直接答案 ＋ 单文件产出物 HTML 三页（正文（去索引）／溯源核验报告／知识专库；顶栏可导出正文 Markdown 与 PDF）。
深知公文写作
dknowc-official-doc-writer		 正式公文 / 事务文书 / 工作材料起草、改写、多轮改稿；两阶段检索（深度搜索广度召回＋可信搜索精准补搜）；研究资料层（研究型文种强制，gate 拦截）；参考范文召回；范文大纲。 双开关交付：命中 15 种法定公文 → Word（可红头）；执行过搜索 → 产出物 HTML 三页；两者可同时成立。
深知可信PPT
dknowc-ppt-assistant		 约束 SVG 逐页创作 → 确定性编译为原生可编辑 PowerPoint（真实形状/文本/图表/表格，非整页图片）；素材检索全程可溯源；多画布（16:9 / 4:3 / 小红书 / 朋友圈 / 竖版 / A4）。 .pptx ＋ 提纲版 / 成稿版两份溯源核验报告（三件套，交付清单外一律不交付）。

dsh 会话隔离

所有脚本产物落 <工作区>/dknowc-output/<会话ID前8位>/official-docs/…（DKNWOC_WS_ROOT 显式指定 > DSH_SESSION_ID 自动隔离 > 回退当前目录）。同一工作区多会话互不混杂、互不覆盖；dsh 以工作区为文件视图，访达也可直达。

dsh Key 三级门禁

DSH_DKNOWC_API_KEY（插件 shell-env 注入，与 MCP Bearer 同源）→ 环境变量 DKNOWC_API_KEY → 本机专用配置文件 ~/.config/dknowc/api_key（600 权限）→ 历史 ~/.zshrc 兜底。配置文件读取不受 dsh 环境变量清理影响，注册成功后本会话立即可用、无需重启。

跨会话持久数据

公文写作的个人素材库与写作偏好存 ~/.dknowc-writer/；可信PPT 的项目目录（内容包 / SVG / 导出产物）存工作区级 dknowc-projects/<项目名>/——均不随会话隔离，插件升级不丢失。

全景流程（从安装到交付）

0
安装插件
dsh plugin --profile web add dknowc-dsh（npm 安装；也支持 GitHub / 本地目录 / dshmarket 市场一键安装）
▼
1
初始化与 Key 检查
skill 被调用时自动运行 initialize.py；dsh 下优先读 DSH_DKNOWC_API_KEY，缺失走三级解析。已有 Key（配置文件 / 环境变量）直接就绪。
▼
2
无 Key → 注册引导需用户确认
手机号验证码两步注册（register_key.mjs / register.mjs）：send 支持短信直发与行为验证链接两分支；成功后 Key 自动写入配置文件，本会话立即可用；注册赠送 10 万积分、实名认证再送 10 万积分。
▼
3
任务路由（模型自动）
咨询 / 检索 / 深度研究 → 可信搜索；做 PPT / 演示文稿 → 可信PPT；写正式文稿 / 公文 → 公文写作。
▼
4
脚本直连检索（全量结构化返回）
可信搜索 / 深度搜索（公文与搜索 skill 均为两阶段）；深度搜索原始产物先经 deep_convert.py 转通用形态再合并（表格标签保留、通道打标）。
▼
5
合并 · 写作 / 综合答案 · 装配溯源 JSON
合并去重（句子指纹＋污染段剔除＋通道拼接）；写作逐处标角标；build_trace_json.py 装配（materials 按角标号升序）。
▼
6
交付前校验gate
check_materials.py（公文）：材料可回溯（URL 全量变体集合判定）、角标一一对应、self_check 五项、研究资料 gate；渲染器内置"答案必须有角标且逐条绑定"硬校验。
▼
7
渲染产出物
三页 HTML（source_note_html.py / render_trace_html.py）、Word（format_document.py，公文开关）、PPTX（svg_to_pptx.py 编译）。
▼
8
dsh 交付
产物已在会话工作区（dknowc-output/<会话ID前8位>/ 与 dknowc-projects/），直接展示脚本打印的路径即可——dsh 以工作区为文件视图，无需交付复制。
MCP 兜底：脚本通道异常时，可经捆绑的「深知可信工作台」MCP 工具（mcp__dknowc__trusted_search / deep_query / doc_outline）应急取数，返回经 mcp_convert.py / adapt_mcp_result.py 规范化落盘；MCP 返回为精简视图，不用于生成正式溯源核验报告。

交付物：单文件产出物 HTML 三页（公文 / 搜索）

页面内容说明
正文（去索引）干净的正式正文（与 Word 正文一致），不带任何角标和链接；顶部是文稿标题。可直接复制使用
溯源核验报告「溯源核验报告：{标题}」→ AI 自验收过程条（检索按接口通道拆分计数、研究资料规模）→ 核验单 → 带角标的正文（角标可点开原文原段引文胶囊）。默认打开页；核验内容只在此页
知识专库全部召回材料卡片（含未引用），按检索分组筛选、可搜索；标题链面包屑、原文摘录、原文链接与存档快照入口、政策文件发文字号、表格按表格渲染（宽表卡内横向滚动）。材料全集，供人工复核

顶部为单一吸顶 banner（文稿名 ｜ 三页切换 ｜ 复制/导出 ＋ 原问题 ＋ 统计行，切页高度不变）；导出菜单：导出 Markdown（正文）／导出 PDF（正文）／导出 PDF（溯源核验报告）。可信搜索不再另生成 .clean.md（正文页与导出已覆盖）。可信PPT 的核验报告为双版（提纲 / 成稿）独立 HTML。

关键约束（红线规则）

红线内容
产物只落工作区bundle 内 skill 目录是只读发布产物；一切运行时产物写会话工作区（dknowc-output/<会话ID前8位>/、dknowc-projects/、~/.dknowc-writer/），禁止写入插件目录。
脚本直连优先正式检索与溯源核验一律走脚本通道（全量返回）；MCP 精简视图仅作应急，不据此生成正式核验报告。
不用模型手写 HTML产出物 HTML 必须由渲染脚本生成，不得自行拼接 <a>／按钮／样式。
角标与素材纪律素材清单先行、逐处标角标、禁止事后补标（继承母版红线；渲染与校验脚本双重拦截）。
Key 安全Key 不入包、不硬编码、不在对话展示完整内容；注册走 dsh 专属渠道码；验证链接展示前经安全校验（同源、精确路径、token 形态），凭据不写公共日志。
额度处理接口返回额度用尽（quota_exhausted）整批停止、禁止重试、引导 MaaS 平台。
版本同步纪律skill 内容改动一律先改 SkillHub 母版，再同步本包重打补丁；本包不独立演进 skill 内容。

接口、Key 与渠道码

检索接口深知可信搜索 V2 https://open.dknowc.cn/open-api/maas/dependable/v2/search（searchType 单值：policy / govSite；参数定档 segmentCount=4 / MaterialLength=18000）＋ 深度搜索接口（deep-query/v3，客户端超时 600s）；MCP 兜底端点 https://mcp.dknowc.cn/s6/mcp/（Bearer 认证）。
API Keydsh 下三级解析：DSH_DKNOWC_API_KEY（插件注入）→ DKNOWC_API_KEY → ~/.config/dknowc/api_key → 历史 ~/.zshrc。用户只需配置 DKNOWC_API_KEY 或经注册落盘配置文件；MCP 的 Bearer 直读 dsh 主进程环境变量（改后需重启 dsh 生效，脚本通道不受影响）。
dsh 渠道码46A3BA1D-3E1A-4E8C-BD50-A6DCBEE1DB05（注册行为渠道细分统计）；来源声明头 channel=dsh；注册 body source="agent" 为 API 合同标记（老用户直接返 Key 放行依据），与声明头 agentSource 是两个不同字段。
注册链路sendMessage 两分支（短信直发 exit 0 ／行为验证链接 exit 2）＋ 退出码 1 错误；X-MaaS 客户端观测四头（Entry-Surface / Client-Name / Client-Version / Client-Instance-Id 服务端签发落盘回传）；pending:true 为密钥准备中非错误。
PPT 编译依赖python-pptx ＋ XlsxWriter（缺失时 uv run --with … 隔离提供，检索与 SVG 创作不受影响）；可选增强 skia-pathops / uharfbuzz。
