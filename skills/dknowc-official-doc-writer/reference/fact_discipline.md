# 事实克制规则

本文件约束所有正式写作任务中的事实边界，防止编造、补写、升级状态和占位残留。它作用于起草、改写、润色、压缩和审查的全过程，不只在执行搜索后生效；搜索素材的使用边界另见 `reference/material_usage_guidance.md`。

## 核心原则

写作只以用户提供材料和经深知搜索确认的素材为事实源。材料没有的，不编造、不推测、不补全。

## 一、材料事实的三种去向

每一条材料信息进入正文前，先判断它属于哪一种：

1. **材料已给且与主旨相关** → 进入正文，保持主体、对象、数字、日期、状态和结论强度，不做改述升级。
2. **材料明确记载未定状态** → 沿用原状态。材料写"拟、建议、待评估、考虑测试、下一步设想"时，正文保持建议、拟办或待评估口径，不升级为已定方案、执行命令或已安排动作。调查、核查、研究等进行中动作用进行态承载。
3. **材料未谈，或与主旨无关** → 直接省略。不补写"下一步""责任单位""完成时限""整改方向""治理闭环""督导流程"等材料没有的内容，不为显得完整而补齐骨架环节。

## 二、禁止补造的内容

以下内容只有材料或深知搜索明确提供时才可写入正文，否则一律省略或文后短列：

- 真实单位名称、政策名称、文号、发布日期、金额、排名、占比、姓名、电话、邮箱、印章、签发人、审批结论。
- 会议的讨论过程、共识、决定（材料只说"组织了会议"时，只写发生和次数，不推断"会议认为""会议强调""达成共识"）。
- 异常的原因结论、责任部门、损失金额、整改方案（材料只说"系统异常"时，按用户原词写，不包装成"核心系统""生产系统"，不补原因和处置）。
- 整改、处置、下一步安排（材料只给问题清单时，正文列明已确认问题及其对象、数量和状态，不新增"已开展处置""下一步安排"章节）。
- 申请、采购、清单类材料的未给字段内容（新增字段只有字段名没有值时留空，不推断发票、票据、邮箱、截止日期等）。
- 超出用户题目时间范围的信息只能作为背景或趋势参考，不得混作当期政策、当期成效或已完成事项。

## 三、状态强度不得升级

- "未定"保持未定：拟、建议、可、考虑 → 不得提升为应、必须、已实施、已确定。
- "进行中"保持进行态：研究、调查、测试中 → 不得写成已完成。
- 个别做法不写成普遍事实：材料只写本单位/本地区做法时，不加"全国首个""领先""唯一""总体较好"等概括判断。
- 缺证据的强评价（显著、长效、全面、基本完成、未影响核心业务）必须回到材料能够支持的直接表述；证据只覆盖局部时，结论范围和强度随之收窄。

## 四、占位符不得残留

交付正文不得残留以下未完成占位，除非用户明确要求输出模板稿：

- `XXXX万元`、`XX单位`、`〔签发日期〕`、`〔会议时间〕`、`（成文日期待确认）`、`YYYY年MM月DD日`、`[具体项目名称]`、`根据用户提供材料填写` 等。
- 用户要求完整落款但未说明成文日期缺失时，可使用当前日期作为草稿日期；用户明示成文日期缺失、待确认或需另行确认时，不使用当前日期补落款。
- 当前日期不得替代会议时间、维护时间、实施期限、政策依据或业务数据。
- 正式签发日期、文号、印章和签发人仍不得编造。

## 五、搜索素材与用户材料的关系

- 深知搜索召回的素材可用于支撑政策依据、数据、案例和表述参考，但素材服务于观点，不得简单拼贴。
- 搜索素材中的事实写入正文时，仍按本文件保持状态强度：接口返回的权威政策可作为依据，但不得夸大适用范围。
- 用户材料与搜索素材冲突时，以用户材料和任务要求为准；无法确认的一致口径不写入正文，只能概括表述。
- 严禁将外省政策作为本省政策依据；搜索素材的出处和边界按 `reference/search_policy.md` 执行。

## 六、改写与压缩的约束

- 以用户最新版底稿和本轮明确补充材料为唯一主线；旧稿、参考样文、公开材料只作结构、语气或检查维度参考，不得自动回流为正文事实。
- 压缩时先锁定不可丢要素：主体、对象、数字、期限、责任、附件、联系人、反馈渠道、请批事项、落款单位和成文日期；不得为变短而删除文种必需要素。
- 去口语化、顺稿、正式化改写只压实原文已有事实，不新增原文没有的组织名称、牵头部门、责任分工、整改动作、督办安排、成果总结或后续处理进展。
- 数据冲突时保持冲突状态，不默认就高或自选最优；只有材料支持时才写区间口径或"最终以主管部门口径为准"。

## 七、文后提示

- 输出模式允许文后提示时，只短列实质缺口及其对当前交付的直接影响，不展开解释"材料缺失"。
- 用户要求只输出正文时，只交正文；材料缺失的事实不写进正文，也不在正文中说明"未提供"。
- 上一轮未补齐的缺口不阻断后续修改；用户要求先确认时，才在正文前提出必要问题。
