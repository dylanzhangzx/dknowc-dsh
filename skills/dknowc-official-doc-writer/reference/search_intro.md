# 深知搜索功能说明参考素材

本文件用于在引导用户开通深知搜索时，向用户介绍深知公文写作的搜索能力。素材仅供 Agent 参考，用于组织自然、简洁的说明；不得逐字照抄本文件，不得用固定模板机械复述，应结合当前任务和用户语气自然表达。

## 搜索能力

深知公文写作的搜索功能可检索权威文件库中的政策依据、权威数据和典型案例，检索结果附原文来源，方便写作时引用和核验。适用于需要政策依据、数据支撑或案例参考的正式材料写作任务。

## 开通方式

如需使用搜索功能，可提供手机号完成验证开通。注册和开通由 Agent 代为处理，无需用户填写单位信息。

## 后续使用

开通后，搜索功能即可在后续写作任务中直接使用。
