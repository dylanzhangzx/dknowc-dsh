# 研究资料规范（研究型文种的写作底稿）

## 定位与适用范围

研究资料是把已召回素材"消化后"的内部写作底稿。素材使用指引解决"材料是什么、用在哪"；研究资料解决"事实全貌、口径与证据链"。生成研究资料后，正文基于研究资料写作，不再边写边从原文摘录里捞取——这是研究型文种分析深度与数据密度的来源。

适用文种：调研报告、政策研究报告、产业研究报告、综合性工作总结、汇报材料等研究型、综合长篇文种。

不适用：通知、函、请示、会议纪要等短公文与小体量事务文书——直接按现有流程写作，不生成研究资料。

## 生成时机与保存（两阶段，与 SKILL.md 搜索规则第 8/9 条对齐）

- **初版（充分性自检时，第 8 条）**：两阶段检索合并、素材分类自检时生成——核心事实总表＋数据与口径表（含纠错记录雏形）；口径表缺口（未给出/未确认/多口径未裁决）驱动数据/案例类补搜，补搜 query 与结果记入初版。
- **定稿（用户确认清单后，第 9 条）**：分主题详述按正文预定章节组织、角标与素材清单序号一致；**正文基于定稿写作**。`check_materials.py` 对研究型文种缺研究资料文件直接拒绝通过——该层是研究型文种分析深度与数据密度的来源，不允许整层跳过。

保存为 `dknowc-output/${DSH_SESSION_ID:0:8}/official-docs/input/标题_研究资料.md`，与同题溯源 JSON 同目录；不向用户交付，供取数复核。

## 内容结构（四部分）

1. **核心事实总表**：一行一个关键事实（事项 / 文件全称 / 发布时间 / 发布主体 / 核心内容 / 材料编号 [n]），覆盖正文将引用的全部政策、数据、案例；同类事实（历年政策演变、多地区做法、多口径指标）优先合并成对比表。
2. **分主题详述**：按正文预定章节组织，每个事实句尾带材料角标 [n]；角标编号与最终溯源 JSON 的 materials 编号保持一致——正文角标直接从研究资料继承，写完正文后按角标整理溯源 JSON。
3. **数据与口径表**：正文涉及的每个数字单列（数值 / 来源 / 发布日期 / 口径说明）；同一指标存在多个取值时，按 `material_usage_guidance.md` 的同指标口径冲突检测裁决，采用最新官方口径并注明调整过程。
4. **核实与纠错记录**：检索核实中发现的名称纠错、口径变化、相互矛盾与裁决依据，单独列出，不混入正文。

## 写作要求

- 研究资料必须"消化"而非"摘抄"：总表与详述用自己的话组织事实，不复制原文段落；引用原文仅限政策条款原句。
- 每个事实必须落到材料编号；无编号支撑的事实不得进入正文。
- **文号只认接口字段**：研究资料与正文中的文号只能来自材料清单 `发文字号` 字段；字段为空时只写文件全称，不得从段落正文提取。政策沿革表可如实写“文号字段未返回”。
- 口径意识：数字必须带来源与时间；跨期数据注明统计口径变化。
- 深度分析：生成研究资料与正文时，以深度思考、深度推理的方式组织"事实—问题—原因—对策"链条；研究型文种按素材充分度展开，分析密度优先于字数，禁止注水；用户明确要求字数时从其要求，未要求时不设默认字数。
- **篇幅与结构**：不设默认下限或上限；章节和条目数量按实际事项需要，不强行凑三段、三条或固定字数。问题与建议按「依据（角标）＋动作＋抓手」组织，长度由事实和判断需要决定。扩充只落在已召回事实上（多引一段＝多一个数字、做法或抓手），不新增形容词；素材不足时宁可短，不补空话。
- 对将被正文直接引用的政策依据型关键材料，以召回段落（每篇最多 2 段）为写作依据；引用条款必须落在召回段落内，段落未覆盖的条款不写入正文（`--full` 仅用于"参考范文召回"，不用于补全政策全文，见 `search_guide.md` 两阶段共同约束）。
- 纠错记录写“正文已注明”前，必须能在正文检索到对应口径说明；不能只写研究资料。否则改为“研究资料已注明，正文未使用该口径”。

## 与既有规则的关系

- 事实边界仍按 `fact_discipline.md` 执行，研究资料中的事实强度与素材一致，不得放大。
- 素材四分类、地域边界、口径冲突检测等规则在生成研究资料时前置执行（相当于把 `material_usage_guidance.md`"写作前的内部整理"清单落成文档）。
- 溯源核验报告的材料、角标与核验口径不变；研究资料只是写作中间层，不进入报告。
