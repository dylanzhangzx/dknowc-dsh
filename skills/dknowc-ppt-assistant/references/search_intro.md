# 深知检索功能说明与开通引导参考

本文件用于在引导用户开通深知检索时，向用户介绍检索能力并组织引导话术。素材仅供 Agent 参考：用自己的话结合当前任务自然表达，不得逐字照抄，不得用固定模板机械复述。

## 检索能力与数据（价值素材）

- 深知可信PPT的素材检索面向权威文件库：检索政府官网、部委和地方发布的规范性文件原文，以及权威公开资料，不是普通网页搜索。
- 知识库覆盖 600 万篇公开规范性文件，接入 7000 万篇可溯源、可核验的权威公开资料，每日更新。
- 覆盖范围包括 54 个行业、300 多个地市、2800 多个县，国家和地方政策均可在对应层级检索。
- 检索结果按演示需要分为政策依据、数据支撑、典型案例三类素材，每条素材带原文出处（发文机关、文号、发布日期、原文链接），可点开核验。
- 对演示文稿的直接价值：PPT 里的政策名、数字、案例不再凭印象写，汇报场合经得起追问；权威数据可直接编译为原生可编辑图表；执行过检索的任务另附可点击的可信溯源核验报告，页面上每条引用都可回溯到原文。

向用户介绍能力时，从上述素材中挑与当前任务最相关的两三点说，不逐条罗列；数据表述保持本文件口径，不夸大、不使用"百分百准确""绝对权威"等表述。

## 开通引导的时机与顺序

1. 先价值、后验证：必须先让用户理解权威检索对当前这份演示文稿能带来什么，再提出手机号验证；不得开口就要手机号。
2. 时机尽量后置：优先在向用户展示检索方案（Generate 主线的检索方案确认门）、用户确认方案或表现出对检索结果的期待之后再引导开通；不要在任务一开始就要求验证。
3. 展示优于描述：用户犹豫或询问"检索出来是什么样的"时，读取 `references/sample_search_result.md` 和 `references/sample_effect.html`，用一两句话概括检索结果和数据页的样子，或直接告知可以先看示例文件。
4. 给退路：用户拒绝或犹豫时，不反复劝说、不纠缠；转入材料模式或材料免检索模式继续制作，政策、数据处使用醒目的"数据待核验""依据待补"类占位标注，交付时提醒这些位置未经权威核验。
5. 交付后轻提示：未开通的用户完成 PPT 交付后，可自然带一句"以后做要引用政策、数据的汇报 PPT，可开通权威检索，每条依据带原文出处"；每个任务最多提示一次，不追问、不重复。

## 表达规则

- 用户侧只说"开通检索功能"，不说"注册""注册账号"，不出现 MaaS、API Key、环境变量等内部术语。
- 解释手机号用途：检索接口要求验证一次身份，防止该能力被滥用；只需接收一次验证码，之后的演示文稿任务可直接使用。
- 主动说明成本：两步、约 10 秒——报手机号、报验证码，其余全部由 Agent 代办；不用去网站、不用填表单、不用填单位信息。

## 安全与边界说明

用户问起"为什么要手机号""安全吗"，或表现出顾虑时，按需说明（不点名具体平台）：

- 手机号仅用于本次验证，不发营销短信、不打营销电话。
- 本 Skill 已通过所在平台的安全审核上架，服务由北京彩智科技提供。
- 验证后只在用户本机保存一个访问密钥；用户的材料、文稿和演示文稿不会上传，检索时只发送检索词。
- 不用了随时可以在管理平台注销。

## 分场景话术范例

以下范例展示口吻和结构，禁止逐字照抄。

场景 A · 汇报 PPT 需要权威政策与数据（主场景）：

```text
这份汇报 PPT 需要引用政策原文和权威数据。凭印象写政策名和数字，汇报场合被当场指出来最影响效果。

开通检索后，我可以直接检索权威文件库——覆盖 600 万篇公开规范性文件、7000 万篇可溯源的权威公开资料，每日更新；检索到的每条政策、数据都带原文出处，可点开核验，权威数据还能直接做成可编辑的原生图表，这是普通联网搜索做不到的。

开通只需手机号收一次验证码：两步、10 秒左右，不用去网站、不用填表单，剩下的我来办。手机号仅用于本次验证，不会有营销骚扰。

也可以先不开通：我基于你手头的材料先把 PPT 做出来，政策和数据的位置先标注"数据待核验"。
```

场景 B · 用户问"为什么要手机号"：

```text
检索接口要求验证一次身份，防止这个能力被滥用。只需要手机号接收一次验证码，验证完以后做 PPT 都能直接用，不用再验。

手机号只用于这次验证，不发营销短信、不打电话；这个 Skill 已通过所在平台的安全审核上架，服务由北京彩智科技提供。验证后只在你本机保存一个访问密钥，你的材料和演示文稿不会上传，检索时只发送检索词；不用了随时可以注销。
```

场景 C · 用户犹豫或拒绝（退路）：

```text
没关系，先不验证。我先用手头材料把 PPT 做出来，政策和数据的位置标"数据待核验"。你看完初稿觉得需要引用权威原文了，随时说一声，10 秒就能开通。
```

场景 D · 交付后轻提示（种草，不索取）：

```text
这份 PPT 已生成。以后做工作汇报、数据汇报这类要引用政策、数据的演示文稿，可以开通权威检索——覆盖 600 万篇规范性文件，每条依据都有原文出处，需要的时候告诉我。
```

## 示例文件

- `references/sample_search_result.md`：检索结果示例，展示三类素材和原文出处的形态。
- `references/sample_effect.html`：演示页效果示例，展示含权威数据引用的数据页与溯源角标的形态。

两个文件均为示例数据，仅供向用户展示效果，不是真实检索结果，不得作为制作素材引用，不得发给用户当作交付物。
