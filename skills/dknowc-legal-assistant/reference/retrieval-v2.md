# 路径一：可信搜索接口 V2（主路，强制先跑）

> 读本文件之前不要调用 `legal_search.py --law`。任何法律检索的第一步都是这里。

## 接口契约

- 入口：`POST /open-api/maas/dependable/v2/search`，脚本封装为 `legal_search.py --query`
- 粒度：`searchGranularity=PROVISION`（条款级），返回的是**条文段落**，带条文标题、原文、来源链接
- 固定参数（脚本已带）：`searchType=["policy"]`、`validityFilter=false`、`segmentCount=6`、`MaterialLength=25000`、`filterPara=true`、`dataAuthority=true`
- 标签：`policyLabels` 传**完整路径数组**，多个标签按且（AND）召回；路径规则见 `tags.md`

## 查询写法

一部法一条**聚焦短查询**，不要把整段案情和规则混写成一条长句（实测长混写更容易返回 0）。

| 用法 | 写法 | 例子 |
|---|---|---|
| 按法批量 | 法名 + 该法多条规则措辞 | `劳动合同法 协商一致解除 经济补偿 每满一年一个月工资 三倍封顶 代通知金 二倍赔偿` |
| 条号补漏 | 把缺的条号直接写进 query | `第三十六条 协商一致 第四十一条 裁减人员` |
| 事实查漏 | 事实要素 + 规则措辞 | `上下班途中 非本人主要责任的交通事故 工伤认定` |

纯用户原话召回差（实测无关文档排第一）；文档名式查询最准。

## 标签怎么加

按文件族决定，不要按“是不是法律问题”决定：

| 文件族 | 标签 | 说明 |
|---|---|---|
| 法律本体（XX法） | `法律/法律标签/法律` | 可用短名「法律」，脚本按目录补全 |
| 行政法规/条例 | 不加 | 只带政策族标签，没有统一标签 |
| 司法解释/批复/规定 | 不加 | 主题标签按主题/行业分散，没有统一标签 |
| 地方性法规/规章 | 不加 | 同上 |

标签的具体路径、目录校验命令见 `{baseDir}/reference/tags.md`。

## 带标签返回 0 条

- **不自动降级**。结果里 `_legal.label_zero=true`，如实记录“带标签 0 条”。
- 如确需无标签结果，**另发一次独立检索**（不带标签），两次分别落盘、报告中分别展示。
- 不得在同一命令里偷偷去掉标签重查。

## 结果怎么用

- `content.data.检索文章[].段落[]` 是条款级段落，`标题` 含条号（如“第四十七条 经济补偿标准”），`内容` 是原文。
- 语义段落可直接作引用依据的条件：本身是原文、条号可核对、**非版本敏感**。
- 版本敏感问题（新旧法、废止法、时间效力）不能用 V2 段落直接下结论——V2 没有版本字段，转 `retrieval-statute.md` 用 `--reference-date` 取当时版本。
- **日期字段不是“版本日期”**：`发布日期` 可能取的是法律原始施行日或镜像抓取日，`生效日期` 也可能是原始法施行日，不等于当前版本的修正公布日/施行日。不要把 V2 的 `发布日期` 直接写成“现行版本日期”。
- **看到 `失效日期` 先当旧版处理**：`失效日期` 早于问题基准日（或今天）时，该材料是旧版本，报告材料卡要标“旧版材料、失效于 YYYY-MM-DD”，并走法条模式确认现行版本；不能把旧版条文当现行法结论。

## 必须记录的异常

以下情况写进研究资料，并在报告材料卡/核验单体现：

- 带标签 0 条（`label_zero`）
- 返回的 `文件标签` 不在本地标签目录
- 同一部法多副本标签不一致
- 返回的效力状态与正文修正日矛盾

## 什么时候转法条模式

四个条件任一触发才用（见 `retrieval-statute.md`）：

1. V2 两轮（带标签 / 不带标签）均为 0 条
2. 目标条号没召回，或段落不完整/没带条号
3. 版本敏感，需要按基准日取当时版本
4. 需要核对条文是否被截断

## 政策文件没有“第X条”时：走库内全文，不要直接跳 WebSearch

地方政策、政府办公厅文件常用“一、二、（一）”结构，没有“第X条”可切。V2 对这类文件的召回也不稳定（精确标题也可能 0 条），但政策条件筛选（001）往往能按标题找到。

处理顺序：

1. **用户点名文件全名/文号时，必须先用 `--law "文件全名"` 走 001**；V2 返回 0 条不等于库内没有。脚本会下载全文；如果没有“第X条”，自动返回一个 `正文` 材料（`检索类型=legal-policy-fulltext`），不再报“未能切出目标条文”。
2. 用 `--law "文件全名" --keywords "关键词"` 时，若无条标题，也会回退全文；引用时按文件里的“一、（一）”章节定位，不要编条号。
3. 001 也找不到，或命中的是旧版/同名地方文件时，再走阶段二/三 WebSearch；外部材料内部标 `非官方来源=True`，报告徽标按来源等级展示（政府域名/官方机构「公开网络·官方」，其余「非官方来源」）。
4. **“最新/2026/现行”是版本敏感信号**：库内文件日期明显早于问题日期时，不能把库内旧版当现行；必须 WebSearch 核对是否有新文。报告里写清“库内为某日期版本、外部为新版”，再决定用哪版。

反例（2026-11-10 实测）：

- 安吉 2026 民宿消防：库内有同名 2016 年省级指导意见（无“第X条”），但没有 2026 年浙政办发〔2026〕40号；V2 精确标题 0 条。正确做法是库内全文 + WebSearch 新文，不能拿 2016 版回答 2026 问题。
- 安溪 2026 基础养老金：库内有 2014 年闽政〔2014〕49号（无“第X条”），但没有 2025 年闽人社文〔2025〕43号；190 元数值只能走 WebSearch，同时用库内 2014 文解释制度框架。

## 阶段二/三：库内不足时的外部补充

**触发条件**（不能因为单条 query 0 条就触发）：V2 带标签/无标签与法条模式都拿不到直接条文；或核心事实（法条、司法解释、监管口径、时效、适用范围）无直接支撑；或材料方向冲突且版本链无法裁决。

**阶段二：深知联网（`searchChannel=webSearch`）**

```bash
python3 {baseDir}/scripts/legal_search.py \
  --query "境外网站 中文标签 十倍赔偿 食品安全" \
  --search-channel webSearch \
  --output legal_external_stage2.json
```

**阶段三：宿主 WebSearch**

宿主 WebSearch 原始结果先落 `<run>/legal_websearch_raw.json`，再转换（`--run <run>`）：

```bash
python3 {baseDir}/scripts/websearch_convert.py legal_websearch_raw.json \
  -o legal_websearch_converted.json
```

转换产物与库内 JSON 用 `merge_search_results.py` 合并；外部材料会带 `非官方来源=True`（非库内标记）、`来源通道=外部联网`、`来源性质=政府网站/官方媒体/次级媒体`、`文件标签=["外部联网"]`。

**用途边界**

- 可参与：回答、核验、线索、背景、LPR/汇率/统计等外部公开数据；官方页面用于回查。
- 外部材料与库内材料一样参与 AI 核验、可挂角标；报告用户可见标签为“外部公开材料 · 来源性质”，由用户判断该来源是否足够权威。
- 法条原文/条号、司法解释、现行/废止、时间效力、适用范围、处罚幅度/期限、地方口径仍优先使用深知原文；外部材料用于这些内容时，报告需保留“外部公开材料 · 来源性质”标记并尽量给出官方原文链接。

## 命令

```bash
python3 {baseDir}/scripts/legal_search.py \
  --query "劳动合同法 经济补偿 三倍封顶 十二年" \
  --policy-labels "法律" \
  --output legal_q1_v2.json
```

- `--output` 写 `--run` 目录下的文件名；目标已存在会拒绝（换文件名或换 run 目录）
- 落盘后 `json.load` 校验 `content.data.检索文章`；0 条也要落盘并在研究资料中记录

## 已知限制（不要据此改查询绕行）

- 同一请求存在非确定性（0 条与非 0 交替），见 `troubleshooting.md`
- 标签过滤可能波动，完整路径也会返回 0
- 效力状态字段可能错标

遇到以上情况：记录，不掩盖。
