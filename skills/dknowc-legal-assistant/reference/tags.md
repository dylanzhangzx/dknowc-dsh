# 标签目录与路径规则

## 目录文件

- `reference/policy_tags.json`：裁剪版 250 条（法律 15、主题 128、行业 107；ICS 未收录）
- 全量清单（1,633 条）保留在内部工作区，不随公开包分发；skill 运行只需要 `reference/policy_tags.json` 的 250 条

每条含：标签类型、一级/二级分类、最终标签名、标签 ID、标签编码。

## 路径规则

**接口要的 `policyLabels` = 族 + 类型 + 目录名称**，目录里的「最终标签名」就是完整路径：

| 目录里的名称 | 接口路径 |
|---|---|
| 法律/民法商法 | `法律/法律标签/法律/民法商法` |
| 财政、金融、审计/税务 | `政策/主题标签/财政、金融、审计/税务` |
| 税务行业 | `政策/行业标签/税务行业` |
| 社会保障 | `政策/主题标签/劳动、人事、监察/社会保障` |

- 只传叶子名（如「市场监督管理行业」）不生效，必须完整路径
- 多个标签按且（AND）召回
- 父级路径（如「法律」「政策/行业标签」）可命中子标签，但文档未定义该语义，行为不稳定

## 按文件族决定标签

| 文件族 | 是否加标签 |
|---|---|
| 法律本体 | 加 `法律/法律标签/法律` |
| 行政法规/条例 | 不加 |
| 司法解释/批复/规定 | 不加（主题标签按主题/行业分散，无统一标签） |
| 地方性法规/规章 | 不加 |

## 工具

```bash
# 短名 → 完整路径（唯一命中才返回；父级前缀原样返回）
python3 {baseDir}/scripts/tag_catalog.py --resolve 金融监管行业

# 校验一次检索结果里的所有 文件标签
python3 {baseDir}/scripts/tag_catalog.py --check <run>/legal_q1.json

# 列出某一类的全部路径
python3 {baseDir}/scripts/tag_catalog.py --type "【DT】行业标签"
```

`legal_search.py --policy-labels` 已内置短名解析：直接传「法律」「金融监管行业」即可，脚本会补全；解析不到或歧义时按原值传给接口并在 stderr 提示。

## 已知限制

- 同一部法的不同副本标签可以完全不一致（食安法四份副本全在政策族、公司法副本法律/政策混合）
- 标签过滤结果会波动：同一完整路径也可能返回 0 条
- 以上问题记录到 `troubleshooting.md`，不据此改查询绕行
