# 深知可信检索结果示例（仅供展示）

> 本文件为效果展示样例：以下素材为示例格式，不是真实检索结果。仅用于向用户说明"检索结果长什么样"，不得作为检索依据引用，不得写入回答。

示例任务：查询"企业购置节能节水、安全生产专用设备的企业所得税抵免政策"。

## 召回材料（示例形态）

**材料 1**
- 文章标题：财政部 税务总局关于节能节水、环境保护、安全生产专用设备投资抵免企业所得税有关问题的通知（示例标题）
- 数据源：财政部官网（规范性文件）
- 发布日期：2025-XX-XX
- 相关段落：企业购置并实际使用列入《环境保护专用设备企业所得税优惠目录》等目录内的节能节水、环境保护、安全生产专用设备的，该专用设备投资额的 10% 可以从企业当年的应纳税额中抵免；当年不足抵免的，可以在以后 5 个纳税年度结转抵免……
- 原文链接：可点击跳转原文页面
- 知识专库原文：可点击查看知识专库收录版本

**材料 2**
- 文章标题：某省税务局节能节水专用设备抵免企业所得税操作指引（示例标题）
- 数据源：某省税务局官网（办事口径）
- 发布日期：2025-XX-XX
- 相关段落：申报时需填报专用设备投资额抵免明细，留存专用设备购置发票、目录归属证明备查；跨年度结转抵免应在申报表中逐笔登记……
- 原文链接：可点击跳转原文页面

## 其他返回信息（示例形态）

- 用户问题、咨询日期、办理地域：随检索请求返回
- 知识专库链接：完整召回内容可在知识专库中查看（含全部材料与段落）

## 这些素材如何进入交付

- 每条写入回答的关键结论（政策名、文号、比例、金额、办理条件）都会标注来源角标（如 [1]、[2]），角标与上述材料一一对应。
- 正式回答交付时同步生成三件套：直接回答（带角标）+ 可点击溯源 HTML（点击角标展开对应材料原文摘录，右侧来源面板可查看原文链接）+ 移除角标的干净 Markdown。
- 找不到直接依据的结论不会被强行挂角标，会标注"待核验/需以主管部门口径为准"。
