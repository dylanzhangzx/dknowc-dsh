# 可信搜索接口 V2 · 检索主路（任何检索前必读）

## 定位

可信搜索接口 V2（`POST /open-api/maas/dependable/v2/search`）是税务检索**主路**：条款级（PROVISION）语义召回，直接返回"文章元数据 + 条款段落原文"。政策条件筛选/正文/版本/下载只在 V2 没取全、需要核对全文或版本时兜底（见 `retrieval-policy.md`）。

## 调用

```bash
python3 scripts/tax_search.py \
  --query "增值税 小规模纳税人 免征增值税 月销售额 标准 2023" \
  --policy-labels "政策/主题标签/财政、金融、审计/税务" \
  --out ./runs/<任务>-<时间> --output tax_search_v1.json
```

## 参数口径

| 参数 | 取值 | 说明 |
|---|---|---|
| `--query` | 一税种/一事项一条聚焦短查询 | 不要整段案情混写；文档名式查询最准；**加年份词（如"2023"）能显著收敛年度混排** |
| `--policy-labels` | 完整路径，逗号分隔 | 可传短名（税务/税务行业/社会保障）由 tag_catalog 自动解析；多个标签按且（AND）召回 |
| `--service-area` | 地域（如 北京市） | 可选；传后要核对结果是否真的限定在该地 |
| `--limit-articles` | 默认 10 | 最多返回材料数 |
| `--segment-count` | 默认 8 | 每篇返回段落数 |
| validityFilter | 固定关 | 设 true 召回经常为 0，不用于常规检索 |
| return_full_content | 不用 | 返回全文含站点导航杂质，还挤占 MaterialLength；全文走 `--file` |

## 返回结构

`content.data.检索文章[]`，每篇含：`文章标题`、`发文字号`（脚本已补映射为 `文号`）、`发布或实施机构`、`发布日期`、`生效日期`、`文件标签`（完整路径数组）、`数据源`、`源网址`、`数据权威性`（权威/非权威）、`段落[]`（`标题`/`内容`/`来源链接`）。

引用时用 `段落[].内容` 作依据，保留文件全称、文号、发布日期、条款/章节。

## 带标签 0 条的处置（硬规则）

1. 如实记录：结果 JSON 的 `_tax.label_zero=true`，stderr 有提示。
2. **不要静默去掉标签重查。** 可原参数重试一次（V2 有非确定性，2026-11-06 实测同查询几分钟内 0→5）。
3. 仍 0 且需要继续：**另发一次不带标签的独立检索**，两次分别落盘（`tax_search_label.json` / `tax_search_nolabel.json`），答案里如实写"带标签本次未召回，以下为无标签检索结果"。同一任务的所有检索都写同一个运行目录：首次用 `--out`，后续补查用 `--run`（同名不覆盖，换文件名即可）。
4. 0 条不等于"库里没有"，答案写"本次未召回"，不写"无相关政策"。
5. 库内仍无直接支撑时，**先用 `--file "文件全名"` 做库内确认**（001 全文兜底；找不到或只命中旧版才降级），再按 `reference/websearch-fallback.md` 三阶段降级（阶段二联网、阶段三宿主 WebSearch）；外部材料内部标 `非官方来源=true`，报告按来源等级打「公开网络·官方」／「非官方来源」徽标；0 条不再直接止步于"待核验"。

## 年度混排（必防）

单次检索会同时返回同一政策多个年度的口径（测试实测：申报期限题一次返回 2002-2025 共 8 个年份；免征线 10 万/15 万同屏；扣除标准 1000/2000 元同屏）。处置：

- query 里带年份词；
- 引用时按"文件全称 + 文号 + 发布日期"锁定版本，优先最新公告；
- 答案写明适用纳税年度；用户问历史年度时按当年口径并标注"当时有效"。

## A/B 对照（测试/取证场景）

同一 query 跑两次：一次 `--policy-labels`、一次不带；两份分别落盘。用于评测标签增益或排查标签异常，日常问答不强制。

## 检索后立即做的事

1. `json.load` 校验落盘文件可解析；
2. 扫描 `文章标题` 是否有异常值（如 "502 Bad Gateway"——数据侧已知问题，如实展示来源但不要引用其内容）；
3. 记下每篇的文号与日期，无文号的镜像副本在引用时降级（只引标题+日期+源网址，或换带文号副本/`--file` 核对）。
