# 标签体系（tags）

## 一句话

**标签是领域围栏，不是领域分类。** 它能把检索圈进税务/社保域（实测 B 臂 186/186 篇文章全部携带所传标签），但不能区分税种、事项、年度（目录里没有对应节点，测试确认行为一致）。

## 税务/社保相关的全部节点（全量目录 1,633 条中核对）

| 族 | 完整路径（接口要的就是这个） | 用途 |
|---|---|---|
| 主题标签 | `政策/主题标签/财政、金融、审计/税务` | 税务领域围栏，**默认** |
| 行业标签 | `政策/行业标签/税务行业` | 税务行业围栏（与主题标签高度重叠，单独用场景少） |
| 主题标签（社保族） | `政策/主题标签/劳动、人事、监察/社会保障` | 社保细则（缴费基数、社保减免）**必须切到这个族** |
| 行业标签（相邻） | `政策/行业标签/人力资源和社会保障行业` | 人社行业文件，常与社保主题标签同现 |

## 规则

1. **只传完整路径**。只传叶子名（"税务"）不生效。短名可由脚本自动解析：
   ```bash
   python3 scripts/tag_catalog.py --resolve 税务        # → 政策/主题标签/财政、金融、审计/税务
   python3 scripts/tag_catalog.py --resolve 社会保障    # → 政策/主题标签/劳动、人事、监察/社会保障
   ```
2. **多个标签按且（AND）**——会收窄不是并集；需要并集效果时分别检索再合并。
3. **不依赖父级路径**（`政策/行业标签` 这类）：行为未定义、不稳定，不进正式流程。
4. **社保与税务是两个族**：
   - 查社保细则（缴费基数/社保减免）→ 社保族；
   - 查"税务视角的社保"（减税降费、社保费率降低文件）→ 税务族（这类文件主主题是税）；
   - 实测边界：社保 query × 税务标签不返回 0，而返回带税务标签的减税降费文件；社保主主题文件会被排除。
5. **带标签 0 条**：如实记录、可重试一次、另发无标签对照（见 retrieval-v2.md）。2026-11-05 证据：同一完整路径 8 次里 3 次 0 条；2026-11-06 本项目又复现 1 次（同查询几分钟内 0→5）。

## 怎么选（决策树）

```
问题主体是什么？
├─ 税（个税/增值税/企税/征管/优惠/复议/发票…） → 税务主题标签
├─ 社保缴纳、基数、待遇、社保减免            → 社保主题标签
├─ 减税降费、社保费率降低（以税为主的综合政策）→ 税务主题标签
└─ 说不清 / 跨域 → 先无标签检索看召回构成，再决定加不加标签
```

## 校验返回标签

```bash
python3 scripts/tag_catalog.py --check ./runs/<任务>-<时间>/tax_search_v1.json
```

列出接口返回的、目录里不存在的标签路径（多副本标签治理问题），记录到研究资料，不据此改查询。

## 不要做的事

- 不要自己造"标签→税种"映射假装接口支持税种分类；
- 不要因为一次 0 条就改路径/改查询绕行；
- 不要把"税务"标签当"个人所得税"标签用——年度与税种区分靠 query + 文号/日期本地归类。
